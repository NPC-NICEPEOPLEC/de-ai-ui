# 交付前自查清单

逐条打勾。`[规则ID]` 对应 `scripts/slop-lint.mjs` 的输出；带 ID 的条目检查器能自动查，没有 ID 的需要人眼。

先跑一遍机器检查：

```bash
node scripts/slop-lint.mjs . --fail-under 85
```

## 几何与描边

- [ ] 嵌套圆角满足 `r = R − p`，内外同心 `[判断]`
- [ ] 同层同圆角，全站圆角值 ≤ 4 种 `[R002]`
- [ ] 所有圆角在 4px 网格上 `[R001]`
- [ ] 没有 0–4px 之间的"事故圆角" `[R003]`
- [ ] 描边统一 0.5px `[L001]`
- [ ] 低分屏有 1px 回退 `[判断]`
- [ ] 没有卡片左边缘彩色竖线 `[L002]`
- [ ] 没有卡片套卡片 `[D001]`
- [ ] 没有同时用阴影 + 描边表达同一层级 `[判断]`

## 颜色

- [ ] 界面 chrome 只有黑白灰 `[C003]`
- [ ] 没有紫色 / 紫蓝渐变 `[C001]`
- [ ] 按钮上没有渐变 `[C002]`
- [ ] 颜色走成套 token（Radix 或等价色阶）`[判断]`
- [ ] 品牌色只出现在约定的位置上 `[判断]`
- [ ] 正文文字对比度 ≥ 4.5:1 `[判断]`
- [ ] 深色模式素材单独设计，没有滤镜反转 `[判断]`

## 字体与排版

- [ ] 字号 ≤ 4 档 `[T001]`
- [ ] 最小字号 ≥ 12px `[T002]`
- [ ] 没用 Instrument Serif / Space Grotesk / Bricolage Grotesque `[T003]`
- [ ] 没有全大写小标题 `[T004]`
- [ ] 中文栈先西后中 `[T005]`
- [ ] 字体栈有 sans-serif 兜底 `[T006]`
- [ ] hero 不超过 64px `[T007]`
- [ ] 没有标题上方的眉标 `[Y003]`
- [ ] 没有章节编号 `[Y004]`

## 文案

- [ ] 没有中点「·」分隔符 `[Y001]`
- [ ] 正文没有 emoji `[Y002]`
- [ ] 没有冗余解释性描述 `[判断]`
- [ ] 每个数字都有出处，或已删除 `[判断]`
- [ ] 没有自造词 `[判断]`
- [ ] 按钮文案 ≤ 4 字、动词开头 `[判断]`

## 动效与交互

- [ ] 没有超过 400ms 的过渡 `[M001]`
- [ ] 没有 ease-in `[M002]`
- [ ] 没有 `transition: all` `[M003]`
- [ ] 下拉菜单从触发按钮处展开 `[判断]`
- [ ] 按钮按下缩放到 0.97 `[判断]`
- [ ] 下拉箭头图标对齐、随按钮变色、展开旋转 `[判断]`
- [ ] 尊重 `prefers-reduced-motion` `[判断]`

## 布局与结构

- [ ] 没有大面积居中排版 `[A001]`
- [ ] 没有内联硬编码像素 `[A002]`
- [ ] 分割线只保留必要的（大部分应该用间距代替）`[判断]`
- [ ] 移动端 375px 下不横向滚动 `[判断]`
- [ ] 900px / 1280px 下布局不塌 `[判断]`

## 素材与可访问性

- [ ] 只引入一个图标库 `[K001]`
- [ ] 所有图片有 alt `[S002]`
- [ ] 所有图标按钮有 aria-label `[判断]`
- [ ] 键盘可以走完整个流程 `[判断]`
- [ ] 触控目标 ≥ 44×44px `[判断]`

## 停止条件

- `score ≥ 85` 且 P1 为 0 → 可以交付。
- P1 未清零 → 不许交付，不管 P2 多干净。
- 分数连续两轮不再上升 → 停止打磨，剩余项写进交付说明，不要强行凑分。

## 注意：不要为了清单而破坏场景

清单是默认值，不是法律。一条规则明显在伤害当前场景时（沉浸式摄影页强制白底灰字、儿童产品强制全灰），**先说明为什么破例**，再破例。带 `[判断]` 的条目尤其如此。
