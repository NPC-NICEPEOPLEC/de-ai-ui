## 八位设计师

### 1. @Kubai087 枯白啃设计 — 递进式圆角 + 超椭圆

- 帖子：<https://x.com/Kubai087/status/2115469767650021796>（2026-10-28，《999 个小技巧，让你 Vibe 的产品更有质感》第 004 条）
- 原话要点：等距内缩，`内圆角 = 外圆角 − 间距`，内外共用一个圆心；连续圆角 `corner-shape: superellipse(1.25)`，Chrome / Edge 139+ 支持，Safari / Firefox 自动退回普通圆角。
- 附英文 prompt 原文（本仓库 `SKILL.md` 的契约结构参考了它的顺序：从外往里、同层同圆角、最小 4、pill 全圆、4px 网格、`@supports` 渐进增强、最后输出 `element: old -> new`）。

### 2. @ZaynHao — 10 条优化界面 UI 的提示词

- 帖子：<https://x.com/ZaynHao/status/2113456751915982917>（2026-10-23）
- 10 条原文：不用中点「·」；不加冗余解释文字；文案贴合人群；颜色换 Radix UI Colors；光学对齐 + 嵌套同心圆角；线条边框 0.5px；少动画、ease-out、250ms 起步；字号 ≤ 4 种、最小 12px；减少需判断的交互；不随意用圆角阴影、不要卡片左边缘彩色线条。
- 作者自己说明这套「可能带有个人经验」——所以本仓库把 0.5px 和 Radix 都当作**默认值**而非定律，并补了低分屏回退。

### 3. @ianneo_ai 伊恩 — 只用黑白灰

- 帖子：<https://x.com/ianneo_ai/status/2115277214149451968>（2026-10-28）
- 原话：界面显得廉价，很多时候是颜色给多了；按钮、卡片、输入框全是白的灰的，颜色都在照片里；AI 常给渐变按钮、彩色图标、一卡一色，「每个都想抢眼，最后就显得廉价」。
- 可复制的一句话：「界面只用黑白灰，颜色留给照片和内容」。

### 4. @dingyi — AI slop 特征清单

- 帖子：<https://x.com/dingyi/status/2115790005423734818>（2026-10-29）
- 原帖列出的 19 条特征，本仓库逐条落到了 `references/slop-checklist.md` 与检查器规则里。作者称最后一条（下拉菜单按钮的下拉小图标）「最恶心最严重」，几乎没人修。

### 5. @Xian0063 弦 — 8 条设计审美原则

- 帖子：<https://x.com/Xian0063/status/2114306504778256445>（2026-10-25），正文指向 X 长文 `x.com/i/article/2114244217501589504`（需登录，**未直读**）。
- 本文采用的可核实要点：过程纪律 —— 先定义再动手、先出全貌再逐块改（每轮只改一处）、用「目标」而不是「像素」给反馈、统一视觉规则。
- 间接来源：该长文提到的 5 个 AI 设计 Skill（UI UX Pro Max、Taste Skill、Impeccable、Emil Kowalski Skills、Hallmark）未在本仓库复述，避免转述失真。

### 6. @yanliudreamer 妍妍 — 10 个 UI 组件 / 工具资源

- 帖子：<https://x.com/yanliudreamer/status/2113188741452103685>（2026-10-22），正文指向 X 长文 `x.com/i/article/2113182599892152321`（需登录，**未直读**）。
- 本仓库 `references/assets-and-icons.md` 的资源清单属于**间接来源**（推文正文 + 公开转载摘要），请以原长文为准。
- 采用原则：整套界面图标同一风格体系，线条粗细、圆角、比例、视觉重量一致。

### 7. @ricouii — 中文网站 font-family 写法

- 帖子：<https://x.com/ricouii/status/2113462025556996412>（2026-10-23）
- 原话：「先西后中、兼顾主流操作系统、最后以通用无衬线字体（sans-serif）兜底」；三条避坑：先西后中、写英文名、带空格加引号。完整字体栈已收录进 `references/typography-cjk.md`。

### 8. @remixdesigner — 苹果 Preview 图标的 Clear 模式

- 帖子：<https://x.com/remixdesigner/status/2100082157184229741>（2026-09-16）
- 原话：苹果给 Clear 模式的图标单独添加了图层，因为「直接将默认模式的图片转换会显得很脏」。
- 本仓库由此引申的规则（**引申，不是原话**）：不同外观模式（深色 / Clear / 夜间）的素材单独设计，不要靠滤镜转换。
