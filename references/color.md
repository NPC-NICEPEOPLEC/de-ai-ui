# 颜色

## 核心判断

> 界面显得廉价，很多时候是颜色给多了。—— [@ianneo_ai](https://x.com/ianneo_ai/status/2115277214149451968)

AI 出问题的模式高度一致：**给每个元素一个"自己的颜色"**。渐变按钮、彩色图标、一卡一色、只染一个字。每个元素都想抢眼，结果是没有任何东西在说话。

反过来，好的界面把颜色**留给内容**：照片、插画、数据可视化。界面本体退后到黑白灰。

```css
:root {
  /* chrome：只有黑白灰 */
  --bg: #f6f4f0;
  --surface: #ffffff;
  --line: rgba(0, 0, 0, 0.12);
  --text: #1c1c1e;
  --text-muted: #6b6b70;

  /* 品牌色：只出现在明确的位置上，例如当前选中态 */
  --accent: #2f5d50;
  --accent-fg: #ffffff;
}
```

## Radix Colors 的 12 级语义

[@ZaynHao](https://x.com/ZaynHao/status/2113456751915982917) 的第 4 条：把所有颜色换成 Radix UI Colors，并按它的使用规范来用。12 个 step 各自有明确用途，混用就会出"AI 味"：

| Step | 用途 | 典型 token |
|---|---|---|
| 1–2 | 页面背景 / 轻微分层背景 | `--gray-1`, `--gray-2` |
| 3–5 | 组件表面：卡片、输入框、hover 底色 | `--gray-3` … `--gray-5` |
| 6–8 | 边框：6 被动、7 hover、8 强调 | `--gray-6`, `--gray-8` |
| 9–10 | 实心色块（默认态 / hover） | `--slate-9` |
| 11–12 | 文字：11 正文、12 高对比 | `--gray-11`, `--gray-12` |

最常见的错法：拿 step 9 的实色当正文颜色（对比度不够）、拿 step 1 当边框（看不见）、同一页面混两套色阶。

## 品牌色配额

- 先选 **3–5 个**能代表产品的颜色定基调（可以从喜欢的产品里取色）。[@ZaynHao]
- 落到界面上时，品牌色只允许出现在：主按钮、当前选中态、关键数据的强调。**不允许**出现在：图标（除非整套都是品牌色线条）、卡片边框、卡片左竖线、标题里的某一个字。

## 不要做

| 反模式 | 为什么廉价 |
|---|---|
| 紫色 / 紫蓝渐变 | 训练数据里最常见的"科技感"，已经变成 slop 指纹 |
| 渐变按钮 | 按钮是行动的容器，不是视觉主角 |
| 一张卡片一个颜色 | 用颜色区分内容，等于承认版式没有秩序 |
| 只染一个字的强调 | 装饰性强调，读者只会觉得花 |
| 彩色图标混搭 | 图标颜色不受控，界面永远在抢注意力 |

## 深色模式不是"反转"

深色、夜间、Clear 这类外观要**单独设计素材**，不能靠滤镜或自动转换。苹果给 Preview 图标的 Clear 模式单独加了一层图（默认模式下隐藏），因为直接转过去的图"会显得很脏"。[@remixdesigner](https://x.com/remixdesigner/status/2100082157184229741)

对应到网页：深色模式下不要只改背景色，要重新定 `--line` 的透明度、阴影强度、图片的边框和饱和度。

## 对比度底线

- 正文文字 ≥ 4.5:1，大字号（≥ 18.66px 粗体 / 24px）≥ 3:1。
- 灰色文字不要用 `#9ca3af` 这类"看起来柔和"的颜色配白底——对比度 2.8:1，是 AI 界面的高发问题。

## 与检查器的对应

| 规则 | 含义 |
|---|---|
| `C001` | 出现紫色 / 紫蓝渐变 |
| `C002` | 按钮上有渐变 |
| `C003` | 界面 chrome 上出现超过一个高饱和色系 |
